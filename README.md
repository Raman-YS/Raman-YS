# Raman Youssef

I work on applied computer vision and machine-learning evaluation. My current project studies how segmentation masks and classifier choices affect wheat-grain inspection.

## Featured project

[**Wheat Grain Inspection**](https://github.com/Raman-YS/wheat-grain-research) compares YOLO instance segmentation, EfficientNet crop classification, and SAM 2.1 mask refinement. The repository includes experiment reports, per-class results, and a protocol for evaluating the integrated pipeline on a capture-separated holdout.

## Research interests

- Instance segmentation in dense scenes
- Evaluation under class imbalance
- Reproducible comparison of computer-vision pipelines
